Event & Ticket Reservation

Beginner-friendly demo project

How to test

  1. Open /api/users to see demo user IDs.
  2. Open /api/events to see events and ticket tiers.
  3. Use Postman to create a 10-minute hold with POST /api/holds.
  4. Pay using POST /api/payments/mock with approve true or false.
  5. See organizer analytics at /api/analytics/1.

API endpoints

  • GET /api/users
  • GET /api/events
  • POST /api/events
  • POST /api/holds
  • POST /api/payments/mock
  • GET /api/orders/<order_id>
  • GET /api/analytics/1
  • POST /api/jobs/expire-holds

Important

This is a learning prototype, not a production-ready ticketing platform. It uses SQLite and a mock payment endpoint. Production deployment should use PostgreSQL, Redis caching, a real queue/cron worker, secure authentication, and proper payment-provider webhooks.
